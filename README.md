# Minibug
## A fun little Discord bot
Minibug is a Discord bot that was originally built to be a Minecraft companion for my Discord server, but is growing into a companion for any server. She currently has the following capabilities:
- Save coordinates for you Minecraft world
- Play music through Discord voice channels
- Chat with Minibug using OpenRouter
More features are planned, including a profile system and role management for server members. Feel free to contribute and try for yourself!

hope you all enjoy :) 🩷
